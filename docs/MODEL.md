# モデルの設計

## 目的

事前に公表された評価値と利用者の仮説から、複数の展開を生成する。公式レース映像の再現や、実戦に較正済みの勝率予測を目的とする初期版ではない。

## データの流れ

1. `data/current.mjs`、`races.mjs` または出典付きJSONを入力する。
2. 日付、馬番、斤量、評価、仮説の範囲を検証する。
3. 今年・前年の評価を混合し、適性・騎手・展開などを補正する。
4. シード付き乱数で各馬のパフォーマンスを生成する。
5. 同じ試行結果から着順・描画用時刻を作る。
6. 反復結果から1着回数・3着内回数・平均順位を集計する。
7. 利用者が結果を開いたときだけ、別の答えモジュールと照合する。

## 仮説パラメーター

| パラメーター | 初期値・範囲 | 意味 |
| --- | --- | --- |
| 基礎値 | 今年65% + 前年35% | 両方の事前評価があるとき。片方のみならその値 |
| 評価欠損 | 全出走馬の既知基礎値の中央値 | 欠損マークを表示。全頭欠損は実行不可 |
| 斤量 | (58 − 斤量) × 2 | 1kgにつき2ポイントという簡略化。性別等を二重加算しない |
| コース補正 | −5〜5 × 1.3 | 利用者の仮説。初期0 |
| 騎手補正 | −3〜3 × 0.7 | 利用者の仮説。騎手名から自動加点しない |
| 道悪補正 | −3〜3 × 馬場レベル × 1.5 | 利用者の仮説。初期0 |
| ペース | −1〜1 | 負で前残り、正で差し有利を仮定 |
| 個体変動の標準偏差 | 4.5 × ばらつき × (1 + 馬場レベル×0.12) | 評価欠損時は4.5を7へ変更 |
| 共通展開変動 | 正規乱数 × 0.8 | 全馬が同じレースの展開変化を受ける |

全係数は初期実装の仮説であり、実データから推定・最適化した値ではない。欠損の中央値補完も、未評価馬の能力を知っているという意味ではない。欠損馬の高い分散は上振れも増やすため、1着率の解釈には特に注意する。

## 乱数と再現性

xorshift32から `(0,1)` の一様乱数を生成し、Box–Muller変換で正規乱数を得る。出走馬の入力順で乱数の割当が変わらないよう、計算前に馬番順へ並べる。

繰り返し試行は1つの乱数ストリームを進める。観戦の最初の試行は設定シードを使用し、「別の展開で走る」はシードに1を加える。同じ設定・同じシード・同じモデル版で再現できる。別バージョン間の再現性は保証しない。

1着率の標本誤差の近似 `1.96×sqrt(p(1-p)/N)` はエンジンから取得できる。ただしモデルの不確実性や較正誤差を表すものではない。初期画面では精密な実勝率と誤解されないよう表示していない。

## アニメーション

仮想の走破時刻は距離を16.5m/sで割った基準から、パフォーマンス・馬場等で調整する。当該レースの実走タイムは使わない。

v0.3の進行度は `p + (脚質係数×0.06 + A)×sin(πp) + B×sin(2πp)`。Aは−0.035〜0.035、Bは−0.015〜0.015のシード付き乱数。微分は0.6以上となり逆走しない。両項はゴールで0になるため、試行の着順と一致する。未設定脚質は係数0だが道中の仮想的な順位変化は生じる。A・Bは観戦用の仮説で、実際の位置取りを予測してはいない。1倍速は2000mでおよそ15秒、終盤は緩やかに再生する。

コースは1周の楕円で模式的に描画する。実コースの距離配分、コーナー、直線長、衝突や進路妨害は未再現。公式馬番の帯色は枠色を参照する。仮IDは全頭同じ中立色で、未確認の枠色を作らない。写真や映像は使わない。

## 結果の分離

`engine.mjs` は `results.mjs` をimportしない。当該レースの着順、最終オッズ、レース後評価を追加しても、予想値が変わらないことをテストする。

一方、モデルは過去レースを知った後に作成された。入力から結果を除いたことだけで、未知データによる妥当な精度検証になったとは主張しない。実結果は配布HTMLから読めるため、非表示は遊び方の工夫であり不正防止機能ではない。

## 今後の評価方法

1. 将来の対象レースとデータ取得時刻を固定する。
2. レース前にモデル版と設定を保存する。
3. 結果が出た後に予測と比較する。
4. 改善用レースと評価用レースを時系列で分ける。
5. 十分な件数が集まった後、基準モデルとの比較、順位相関、Brier score、較正曲線等を検討する。

この版ではこれらの実戦評価は未実施。

## 開催前データ

登録馬と確定出走馬を区別する。天皇賞（秋）の初期脚質は全頭neutralで、能力資料以外の未知項目から補正を作らない。初期状態でペースを変えても相対評価は変わらない。斤量は定量規定から入力し、当日の確定斤量の確認後に更新する。

カタログは日本時間で開催日を判定する。出典確認から24時間経過した場合は要確認、開催日翌日以降は過去のスナップショットとして扱う。データ更新は運営者が確認した静的JSONの配信であり、JRAから自動取得する仕組みではない。
