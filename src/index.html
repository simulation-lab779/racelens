01 / VERIFIED FACTS

実レースのデータ

開催前のGⅠ登録馬と事前レーティングを収録。登録段階は仮IDを使い、枠順・騎手が未確認であることを表示します。2024年の実レース2件では、実際の着順と払戻で答え合わせもできます。

出典の確認日時はレースごとに表示。公開サイトのデータ更新を確認でき、24時間以上経過した情報には再確認を促します。JRAの出馬表・オッズを自動取得する機能はありません。

02 / A TRANSPARENT MODEL

予想はどう作る？

今年の公表値65%＋前年35%を基礎値とし、片方だけあればその値を使用。両方なければ出走馬の中央値を仮置きして、ばらつきを大きくします。

基礎値 ＋ 斤量補正 ＋ コース適性
＋ 騎手補正 ＋ 展開補正 ＋ 道悪補正
＋ 試行ごとのランダムな変動

係数、脚質、ばらつきは未較正の仮説です。実際の勝率に較正したモデルではありません。レーティングの距離区分、馬齢による成熟、輸送、調教、当日の状態などは未実装です。

03 / REPRODUCIBLE BY DESIGN

観戦と検証がつながる

同じ条件・シードなら同じ試行を再現できます。着順とアニメーションは同じ試行結果を参照します。位置取りは模式的な補間で、実測軌跡ではありません。

本体はJavaScriptの純粋関数。UIと計算ロジックを分離し、未来の着順が予想へ混入しないこと、結果の再現性、同着、仮想精算をテストしています。

04 / BUILD IN PUBLIC

GitHubで育てる作品

ソース、テスト、データ出典、設計書、GitHub Pages用の設定を同梱しています。まず「コードを理解して1つ改修し、テストと理由を残す」ことから。

初期実装はAI支援で作成。自分の担当範囲とAIの支援範囲は開発記録に残します。写真・映像・公式ロゴは使用せず、トラックは独自の図形描画です。
